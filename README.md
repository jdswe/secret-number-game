# 🎯 Adivina el Número Secreto  

🔢 **Descripción:**  
Este es un juego desarrollado con **JavaScript, HTML y CSS**. En él,
se genera un número aleatorio entre **1 y 10**, y tu objetivo es **adivinarlo**.  

🎮 **¿Cómo jugar?**  
1. Se te dará un número aleatorio.  
2. Debes ingresar tu respuesta e intentar adivinarlo.  
3. Si se acaban los números sorteados, **reinicia la página** para seguir jugando.  

✨ ¡Pon a prueba tu intuición y suerte! 🚀
